# Literary Frequencies

A playlist generator for world literature, powered by the Anthropic API.

## How to Run

1. Open Terminal and navigate to this folder:
   cd ~/Downloads/literary-frequencies

2. Install dependencies (first time only):
   npm install

3. Start the app:
   npm start

4. Open your browser and go to:
   http://localhost:3000

5. Paste your Anthropic API key into the field at the top.
   Get a key at: https://console.anthropic.com

## Works Included
- Kafka on the Shore — Murakami
- 1Q84 — Murakami
- One Hundred Years of Solitude — García Márquez
- Oedipus the King — Sophocles
- Selected Stories — Raymond Carver

## To Stop the App
Press Ctrl+C in Terminal.
